SSH Deck — Privacy Policy

Last updated: 16 November 2026 ·

Summary

SSH Deck is a desktop application that runs on your computer. It has no account, no telemetry, no analytics and no advertising. The developer does not receive any data about you or how you use the app. Data only leaves your computer when you connect to something yourself: your servers, your git repository, a package mirror, or an AI provider you configure.

Data stored on your computer

  • Settings, the list of hosts you added, tunnels and preferences — %APPDATA%\SSH Deck.
  • The integrated Cygwin environment and its files — %LOCALAPPDATA%\SSH Deck.
  • AI assistant conversations (optional, can be turned off and deleted in Settings) — encrypted with your Windows account (DPAPI).
  • AI provider API keys — encrypted with your Windows account (DPAPI); never stored in clear text.
  • Your ssh config, keys and known_hosts stay in your own ~/.ssh folder. SSH Deck reads the config; private keys are only handed to the Windows ssh-agent with the standard ssh-add tool, and are never sent anywhere.

Network connections the app makes

  • SSH, SFTP and tunnels to the hosts you choose, using OpenSSH and your own ssh configuration.
  • Your git repository, if your ssh config folder is a git repository (fetch / pull / push you ask for).
  • The Cygwin package mirror, only when you use the Cygwin package manager in Settings.
  • The AI provider you configure, only when you send a question to the assistant (see below).

Connections go through the proxy you configure in Settings, if any.

AI assistant

The assistant is optional. When you ask it something, SSH Deck sends to the provider you selected: your question, the recent output of the active terminal (if "Include terminal output" is on), the session type, its host alias and environment name, and earlier messages of that conversation. Before sending, the app masks text that looks like secrets (passwords, tokens, private keys, credentials in URLs); this can be configured in Settings.

  • Ollama / local servers (e.g. LM Studio): the data stays on your computer or network.
  • Cloud providers (Anthropic, OpenAI or other OpenAI-compatible services): the data is sent to that provider under your own API key and is subject to that provider's privacy policy and terms.

Children

SSH Deck is a tool for IT professionals and is not directed at children.

Resumo

O SSH Deck é uma aplicação que corre no teu computador. Não tem conta, telemetria, estatísticas de utilização nem publicidade. O programador não recebe nenhum dado sobre ti nem sobre o uso da app. Os dados só saem do teu computador quando tu te ligas a algo: aos teus servidores, ao teu repositório git, a um mirror de pacotes ou a um fornecedor de IA que configures.

Dados guardados no teu computador

  • Definições, lista de hosts que adicionaste, túneis e preferências — %APPDATA%\SSH Deck.
  • O ambiente Cygwin integrado e os seus ficheiros — %LOCALAPPDATA%\SSH Deck.
  • Conversas do assistente de IA (opcional; pode ser desligado e apagado nas Definições) — cifradas com a tua conta do Windows (DPAPI).
  • Chaves de API dos fornecedores de IA — cifradas com a tua conta do Windows (DPAPI); nunca guardadas em texto simples.
  • O teu ssh config, chaves e known_hosts ficam na tua pasta ~/.ssh. O SSH Deck lê o config; as chaves privadas só são entregues ao ssh-agent do Windows com a ferramenta padrão ssh-add e nunca são enviadas para lado nenhum.

Ligações de rede que a app faz

  • SSH, SFTP e túneis para os hosts que escolhes, com o OpenSSH e a tua configuração ssh.
  • O teu repositório git, se a pasta do ssh config for um repositório (fetch / pull / push que pedires).
  • O mirror de pacotes do Cygwin, só quando usas o gestor de pacotes nas Definições.
  • O fornecedor de IA que configurares, só quando envias uma pergunta ao assistente (ver abaixo).

As ligações passam pelo proxy que configures nas Definições, se houver.

Assistente de IA

O assistente é opcional. Quando lhe perguntas algo, o SSH Deck envia ao fornecedor escolhido: a pergunta, a saída recente do terminal ativo (se "Incluir a saída do terminal" estiver ligado), o tipo de sessão, o alias do host e o nome do ambiente, e as mensagens anteriores dessa conversa. Antes de enviar, a app oculta texto que pareça segredo (passwords, tokens, chaves privadas, credenciais em URLs); isto é configurável nas Definições.

  • Ollama / servidores locais (p.ex. LM Studio): os dados ficam no teu computador ou na tua rede.
  • Fornecedores na cloud (Anthropic, OpenAI ou outros compatíveis com OpenAI): os dados são enviados a esse fornecedor com a tua chave de API e ficam sujeitos à política de privacidade e aos termos desse fornecedor.

Crianças

O SSH Deck é uma ferramenta para profissionais de TI e não se destina a crianças.
